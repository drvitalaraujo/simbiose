# Pelourinho reimaginado — referências de mapa

Sete conceitos originais para SIMBIOSE, gerados em 2026-10-02 pela ferramenta nativa de geração de imagens do Codex. O endpoint nativo não expõe seleção nem identificador verificável do modelo; não foi usada API paga externa nem fallback de CLI. Origem: geração por IA a partir de `docs/concept/BRIEF.md`, `docs/GDD.md`, `docs/maps/arena1.svg` e inspeção das quatro capturas `docs/screens/arena1-*.png`.

## Uso e limites

A planta real de 120 × 88 m manda em posição, colisão, cobertura, acessos e alturas de piso. As imagens orientam linguagem visual e proporções artísticas, não são plantas de execução. A vista isométrica foi regerada para remover título incorreto e slogans extras, simplificar volumes e tornar legíveis as três rotas. Nas quatro perspectivas, a proporção gerada é 1672 × 941 px (aproximação de 16:9 de menos de um pixel).

Todas as imagens finais são PNG e têm menos de 3 MiB; não foi necessária conversão para JPG. Inspeção visual conferiu contornos, rotas principais, leitura dos módulos e textos em pt-BR. O kit de fachadas oferece as três variações e seis módulos em elevação frontal. A folha de props contém os sete grupos solicitados. Nenhum código foi alterado; testes de jogabilidade/build não se aplicam a esta entrega de arte.

## Regras para construir em Three.js

Usar as cores base exatas da PALETTE: a iluminação cel das pinturas não deve virar cores adicionais no código. Materiais via `toon()`. Paredes/sólidos AABB, props a 0°/90°, degraus de no máximo 0,4 m. Ornamentação próxima de malha atingível com `raycast = () => {}`; pichação e folhas transparentes com `depthWrite: false`. Emissão usa a cor da paleta multiplicada em luz linear; hologramas, fios e grades decorativos não mudam hitboxes. Não copiar cada pedra, parafuso, folha e ripa da pintura: trocar detalhe por planos, textura e silhuetas. Grafites novos precisam atlas novo, pois os existentes estão quase cheios. Mudança de cenário que projeta sombra exige `pipeline.refreshShadows()`.
