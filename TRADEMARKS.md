# Nome e marca

O código é livre (AGPL-3.0-only) e o conteúdo próprio é CC BY-NC-SA 4.0, mas o nome **SIMBIOSE** e
o logotipo do jogo identificam a versão oficial e não fazem parte dessas licenças (a AGPL, seção
7(e), permite reservar o uso de marcas). A licença do código continua valendo inteira para quem
usa o código: esta política só trata do nome e do logotipo.

Pode, sem pedir:

- jogar, estudar, modificar e hospedar o jogo seguindo a licença;
- dizer que o seu projeto é "baseado no SIMBIOSE" ou "um fork do SIMBIOSE";
- usar o nome para falar do jogo (vídeos, lives, artigos, mods).

Precisa de outro nome e de outro logotipo (o seu fork não pode se apresentar como "SIMBIOSE"):

- versão modificada publicada para outras pessoas jogarem (site, loja, servidor público);
- qualquer uso que faça parecer que o projeto é oficial ou endossado pelos autores.

Dúvidas: abra uma discussão no repositório.
